# TopoProbe reproduction guide

Updated 2026-11-10 for the current manuscript.

TopoProbe uses measured board topography for a prescribed probe-to-surface gap and adaptive selection of leakage sites. The internal search implementation is the TopoBO class in topoprobe/topobo.py. Python identifiers and archived record names retain their existing spelling.

## Search comparison

The STM32F429 board runs software AES. The domain has 1748 candidate sites on a 1 mm lateral grid. All search methods use surface following at a 1 mm gap and a 64-query budget. Each query acquires 1024 traces. Every method has five runs and reports recommendations at 32, 48, and 64 queries.

For this board-level comparison, SCNIFFER starts at one uniformly sampled site per spatial quadrant. Swarm starts at three uniformly sampled distinct candidates and acquires four 256-trace corner background batches before its 64 search queries. The implementations retain their gradient or particle-swarm updates and respective scores.

| Method | 32 queries | 48 queries | 64 queries |
|---|---:|---:|---:|
| SCNIFFER | 363.4 | 363.4 | 363.4 |
| Swarm | 1180.2 | 1841.2 | 1868.8 |
| Without topographic guidance | 105.2 | 102.8 | 97.0 |
| TopoProbe | 127.6 | 44.8 | 35.6 |

The entries are mean recovery trace counts at the recommended sites. Fresh validation batches contain 8192 traces for Swarm runs 1–3, 4096 for Swarm runs 4–5, and 1024 for the other searches.

The recovery procedure first finds the earliest tested checkpoint for which that checkpoint and all later tested checkpoints recover every key byte. It then bisects the bracket between the preceding checkpoint and that successful checkpoint, stopping at a one-trace bracket and reporting its successful upper endpoint. This is the operational recovery threshold used in the stored results.

## Offline checks

    pip install -r requirements.txt
    python checks/replay_all.py
    python checks/check_gap_pairing.py

The replay checks all recorded queries and recommendations for 20 runs. The pairing check validates plaintext-seed equality for every fixed/following pair, distinct streams across sites and repetitions, and the seeds actually passed through a mocked acquisition loop. These checks run offline.

## Paired height experiment

Section IV-C1 and Table III compare fixed-plane and surface-following acquisition at three fixed sites. The fixed plane uses the chip-top height plus approximately 0.5 mm. Surface following uses each site's height plus approximately 0.5 mm. The table reports the first successful discrete checkpoint among 256, 512, 1024, 1536, 2048, 3072, 4096, 6144, and 8192 traces.

| Site | Fixed plane | Surface following |
|---|---|---|
| Capacitor A | >8192, 8192, 8192 | 2048, 3072, 3072 |
| Low-board site | 3072, 6144, 4096 | 256, 512, 256 |
| Chip top | 2048, 1536, 2048 | 1536, 2048, 2048 |

The updated acquisition script derives seeds from the repetition, site, and batch purpose. Fixed-plane and surface-following conditions share the plaintext sequence for a given site and repetition. Search and validation batches use separate streams. Site identifiers have a fixed seed mapping, so changing the acquisition order preserves pairing.

The data directory contains the original recorded results. The seed correction applies to future acquisition runs.

## Code and data map

- topoprobe/scan.py and surface.py: laser sampling, reconstruction, coordinate registration, and gap control described in Section III-B.
- topoprobe/terrain.py: six topographic classes, using the existing internal class identifiers.
- topoprobe/topobo.py: initialization, topographic priority, nonstationary GP, noisy expected improvement, and weighted selection in Section III-C.
- topoprobe/leakage.py: SNR score in Eq. (2), CPA, and checkpoint-based recovery thresholds.
- topoprobe/baselines.py: SCNIFFER and Swarm implementations for the shared candidate grid.
- topoprobe/gap_ablation.py: paired height experiment in Section IV-C1.
- data/runs/: query histories, recommendations, validation counts, and seeds.
- data/summary.json: means and per-run recovery counts for Tables II and IV.
- data/gap_ablation.json: first-success checkpoints for Table III.
- data/height_map.npz and candidates.csv: registered height field and candidate geometry.

The six manuscript classes are IC top, IC boundary, near-IC parts, other small parts, other parts, and bare board. Internal identifiers remain boundary, near-IC, top, other small, other, and bare board. The initial quotas are 3/3/3/2/2/3 in either of these orders.

Recorded sessions retain their calibration metadata. The baseline and ablation candidate heights use a +0.00308 mm session correction. TopoProbe records store the later laser-only registration. Each session uses the prescribed gap relative to its registered surface.

The hardware implementation uses an IAI stage, Panasonic HL-G1 sensor, Langer EM probe with BT706 electronics, PicoScope 3403D, and STM32F429 target. Hardware acquisition requires the configured motion geometry and connected instruments. Calibration and motion checks remain in the executor.
